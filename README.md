# العين الحمرا — Red Eye 👁️

> **EN:** A Chrome extension (Manifest V3) that applies the 20-20-20 rule: every 20 minutes of screen time it asks you to look away for 20 seconds. Your camera tracks your blinking **on-device** (MediaPipe Face Landmarker) and warns you when your blink behaviour suggests tired eyes. No image ever leaves your computer.

إضافة كروم بتفكّرك تريّح عينك كل 20 دقيقة قدام الشاشة (قاعدة 20-20-20)، وبتراقب رمشك بالكاميرا وتنبّهك لو عينك شكلها تعبت.

## المميزات

- **مؤقت 20 دقيقة شغل ← 20 ثانية راحة**، وبعدها الجلسة الجاية بتبدأ لوحدها.
- **شاشة راحة** فوق أي صفحة (عدّاد وحلقة تنفس)، ونافذة بديلة لو الصفحة مش بتسمح (chrome:// مثلًا).
- **عين على الشاشة بترمش مع رمشتك فعلًا** (في نافذة الإضافة)، وبتحمرّ مع الوقت ومع التعب.
- **كشف التعب** من خمس علامات مستقلة: قلّة الرمش، الرمشات الطويلة والبطيئة، الرمش الناقص، تدلّي الجفن عن أول الجلسة، والغفوات القصيرة. لو العلامات استمرت 15 ثانية، بتظهر لك رسالة "عينك شكلها تعبانة، ريّحها" (أو تبدأ الراحة تلقائيًا لو اخترت كده).
- **راحة طبيعية**: لو بعدت عن الشاشة طول فترة الراحة (أو قفلت الشاشة)، الإضافة بتحسبها راحة وتبدأ العدّ من الأول.
- **الخصوصية**: التحليل كله على جهازك، ومفيش أي طلب شبكة. الكاميرا بتقفل في وقت الراحة.

## التثبيت

يلزمك Node.js 18 أو أحدث، وكروم 116 أو أحدث.

```bash
git clone <رابط-الريبو>
cd red-eye
npm install
npm run setup     # بينسخ مكتبة MediaPipe وبينزّل موديل الوش (حوالي 4MB)
```

بعدها:

1. افتح `chrome://extensions` وفعّل **Developer mode**.
2. اضغط **Load unpacked** واختار فولدر المشروع.
3. هتتفتح صفحة الإعدادات: اضغط **شغّل الاختبار** واسمح بالكاميرا، وبص على الشاشة 6 ثواني (معايرة)، وبعدها ارمش وشوف النقطة الحمرا بتومض مع كل رمشة.
4. من أيقونة الإضافة اضغط **ابدأ الجلسة**.

> لو `npm run setup` ما قدرش ينزّل الموديل، نزّله من المتصفح من الرابط اللي بيطبعه الأمر واحفظه باسم `vendor/face_landmarker.task`.

## إزاي بيقيس الرمش

كل إطار من الكاميرا بيعدّي على **MediaPipe Face Landmarker**، وبنطلّع منه إشارة "فتحة العين" من مصدرين:

1. درجات `eyeBlinkLeft/Right` (مقاومة لحركة الراس والإضاءة).
2. نسبة فتحة العين EAR من نقاط الجفن.

الإشارتين بيتدمجوا (70/30)، وبعد **معايرة 6 ثواني** بتتحدد "فتحة عينك العادية". الرمشة بتتحسب لما الإشارة تنزل تحت 60% من المعدل العادي وترجع فوق 78% (فرق بين العتبتين علشان الضوضاء)، ومدتها بين 40 و400 مللي ثانية. أطول من كده بتتحسب "إغلاق طويل"، وأطول من ثانية "غفوة". لما تبص لتحت على الكيبورد أو تلف راسك، القياس بيوقف بدل ما يغلط.

الكود المسؤول عن ده في `src/blink-engine.js` (منطق خالص بدون متصفح) و`src/detector.js`.

## حدود الدقة (بصراحة)

- التحقق من المنطق اتعمل بإشارات تجريبية: الرمشات من 80 مللي ثانية وطالع بتتلقط 100% على 30 إطار/ثانية في الاختبارات. الرمشات الأسرع محتاجة 60 إطار/ثانية (إعداد "سرعة الكاميرا").
- الدقة الفعلية بتتأثر بالإضاءة (الأفضل إضاءة أمامية، مش ضهرك للشباك)، ولمعان النظارة، وزاوية الكاميرا، وجودتها. استخدم صفحة الاختبار تتأكد إن عدّاد الرمش بيطابق رمشك.
- التعب بيتقدّر من **سلوك الرمش**، مش من احمرار العين: الكاميرا العادية مش بتقدر تقيس الاحمرار بدقة. ده مؤشر مساعد وليس تشخيص طبي. لو عندك ألم أو احمرار مستمر كلّم دكتور عيون.

## هيكل المشروع

```
manifest.json            Manifest V3
src/blink-engine.js      كشف الرمش وحساب التعب (منطق خالص + اختبارات)
src/detector.js          غلاف MediaPipe: دمج blendshapes و EAR
src/camera-loop.js       قراءة إطارات الكاميرا وتشغيل الكشف
src/offscreen.*          صفحة مخفية بتمسك الكاميرا طول الجلسة
src/background.js        المؤقت والراحة والتنبيهات (service worker)
src/overlay.js           شاشة الراحة والتنبيه فوق الصفحات
src/popup.*              نافذة الإضافة (العين اللي بترمش معاك)
src/options.*            الإعدادات واختبار الكاميرا
scripts/setup.mjs        نسخ MediaPipe وتنزيل الموديل
```

## رفعها على GitHub

```bash
git init
git add .
git commit -m "Red Eye: 20-20-20 eye rest with on-device blink tracking"
git branch -M main
git remote add origin https://github.com/<اسمك>/red-eye.git
git push -u origin main
```

فولدرا `vendor/` و`node_modules/` في `.gitignore` (بيتولّدوا بـ `npm run setup`). لو عايز الإضافة تشتغل مباشرة من الريبو من غير خطوة التنزيل، شيل `vendor/` من `.gitignore` وارفعه.
